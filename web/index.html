硬件调试 共享电机 + 电磁离合

★ 硬性约束：任何时刻最多只有 1 路离合吸合。 软件层有四重保障（吸合前强制全断开、吸合前回读复核、直接调用拦截、每周期体检）， 所以「离合冲突次数」正常永远是 0。一旦不是 0，请断电检查驱动电路。

手动点动 所有通道统一

秒
响应时间：所有通道统一的「进退响应时间」，只作用于手动点动， 不影响自动换料。填超范围会被自动夹到 0.2 ~ 60 秒。
点动 PWM（2026-09-23 新增）：就是拿来目测"多少占空比能带动电机和电磁离合"的。 默认 100%（duty 255）。从 5% 一档一档往上加，每加一档按一次上面的「进料」， 一边听电机声一边看日志：
· 日志里出现 点动回执…duty=128/255；硬件回读 IN1=128/255(引脚1) —— 信号确实写进硬件了，此时电机不转就是占空比不够，继续往上加；
· 回读 IN1=0/255 而 duty 不是 0 —— 信号没写进硬件，是软件问题；
· 找到"能可靠转起来"的最小值后留一点余量（机构有阻力、料路有弯）， 再把带余量的值填到下面「辅助送料」的 PWM 速度里。 辅助送料默认 100%，宁可有力、不要没力。

电机电流采样 AT8236 ISEN · GPIO3 · 堵转保护

读取中…
电流怎么来的：AT8236 的 ISEN 脚输出电压 = 电机电流 × 采样电阻， 所以 200mΩ 就是 200mV/A。板上的 R11 就是 200mΩ， 换过电阻才需要改这个数。
堵转阈值要先测再用：把阈值填 0（= 只显示、不保护）， 然后按「进料」让它正常送一段，记下「均值」那一列； 再故意卡住料路让它堵转，记下堵转时的值。 阈值取两者中间偏向正常值的那一侧（比如正常 600mA、堵转 1800mA， 取 1200~1500mA）。
为什么会误跳：直流电机起动电流是稳态的 3~8 倍， 所以有「起步屏蔽」这一项 —— 一开始转的那段时间不判。 起步容易误跳就把它调大（800~1200ms）。
芯片自己的硬限流约 2.5A（VREF=5V ÷ (10 × 200mΩ)）。 固件阈值设在 2.5A 以上没有意义 —— 超过之后芯片先斩波， 电流读数会卡在一个平顶上，分不出真假堵转。

辅助送料 换色/流量校准时同步推料

换色 / 校准挤出 / 流量校准 / 打印中，AMS 同步以该 PWM 推料，帮打印机齿轮咬住新料。
阶段内保持离合吸合（2026-09-23 新增，默认开）： 在需要辅助送料的阶段里，电磁离合全程吸着，只有电机按周期脉冲（转 → 停 → 再转）； 离开这些阶段（或者打印机一来换料请求）立刻断开。
为什么要这样：原来每送一次都是一整套"吸合 → 转 → 停 → 断开"， 而校准阶段只停 0.5 秒就再来一次 —— 实测那 3 分 15 秒里离合咬合了 97 次， 线圈和齿轮在反复咬合脱开。保持吸合之后，机械只咬一次。
★ 硬件红线照旧守死：任何时刻最多 1 路吸合。 吸合全部走 clutch_engage()（内部无条件先全断开、回读复核，再吸目标）， 所以"保持"永远不会变成"又吸了一路"；主循环每周期还有一次体检兜底。 「离合冲突次数」正常永远是 0。
⚠️ 若长时间保持后发现离合发烫或有异响，把这个开关关掉即可退回旧行为 （每次吸合-断开），不用换固件。
PWM 速度：默认 100%，范围 5%~100%。 ⚠️ 低于 60% 会带不动本机构的电机 —— 现场表现为"电机没动作、听不到声"， 那是堵转不是没发指令。调的时候一边听电机声一边往上加，直到能听到明显转动。
（2026-09-23 run7 实测：默认值原来是 60%，整轮打印的辅助送料回执全部正常 —— 离合吸合、duty=153 确实写出去了 —— 但料一动不动；同一颗电机跑 100% 的退料/送料都正常。结论：60% 正好压在堵转线上，默认值已提到 100%。）
每次时长：默认 1500ms，范围 200~10000ms。太短推不动料，太长会把料顶过头。
重复频率（跟随上面的"每次时长"，没有单独参数）： 校准期间（校准挤出 / 流量校准）＝ 每次时长 + 停 0.5 秒；打印中 ＝ 每 5 秒一次。 校准阶段中途停一下是为了不把料一直顶死；把"每次时长"往上调，校准时会更密。 默认 1500ms 下，校准时大约每 2 秒送一次（≈ 转 1.5 秒 / 停 0.6 秒）。
怎么确认它真的动了（这条最有用）：先按上面的「立即自检」按钮 —— 它会按你填的速度/时长立刻驱动一次当前通道，不用等下一轮打印。 每次辅助送料后面也会跟一条执行回执，形如 辅助送料回执：离合已吸合 —— 通道2 PWM duty=153/255（60%），通电 1500ms；硬件回读 IN1=153/255(1) IN2=0/255(0)。
duty 是请求写下去的数；硬件回读是 从 LEDC 寄存器读回来的数和引脚的实际电平。 两个一对照，四种情况立刻分清：
· 只有「辅助送料…」却没有回执 → 电磁离合没吸合上，根本没驱动电机， 与占空比无关；
· 回读 IN1=0/255 但 duty 非 0 → 信号没写进硬件，软件问题；
· 回读 IN1=153/255(1)、通电 1500ms，电机还是不转 → 占空比不够，把 PWM 速度拉到 100% 再自检一次；
· 100% 自检（duty=255）也不转 → 接线 / H 桥使能 / 离合打滑， 不是参数问题。此时用「手动点动」（默认也是全速 255，可在上面调）对照， 两者表现应当一致。
网页「硬件状态 → 最近一次驱动 / LEDC 回读」里也有同样的数，不用抓串口。
关闭总开关后换色/打印中都不再同步辅助送料。

换色冲刷参数 生成 change_filament_gcode 片段

合计冲刷量 / 预计耗时 —
这不是"打印机的固定流程" —— 切刀、冲刷、擦嘴全部来自切片机器设置里的 「换料 G-code」（change_filament_gcode），切片时就写死进 G-code 了， 板子改不了已经切好的文件。所以这里生成的是**给你粘回切片器**的片段。
怎么用：在 Bambu Studio / Orca 里打开 「机器设置 → 换料 G-code」，把你现有宏里「冲刷 1」那一行到「最终收尾」结束 整段删掉，换成这里生成的内容，保存后重新切片。 切刀段、暂停段（M73 P101 / M400 U1）、 末尾的 M620/M621 / T{next_extruder} 都不要动。
为什么要调：默认的 4 轮（30/20/15/10 + 首次再加 50mm）是把旧颜色冲干净 的保守值。2026-09-23 run7 实测：一次换色里，从打印机暂停到它说"该你退料了" （切刀 + 吐料）已经要 18~24 秒，resume 之后的 4 轮冲刷 + 擦嘴还要再占十几秒。 轮数减到 2、首次额外量减到 30，一般能省 7~8 秒/次（首次换色省得更多）； 代价是颜色交界处可能略微混色 —— 建议先只减轮数、别一次减太多。
预计耗时是粗算（冲刷按 200/300 mm/min、每次擦嘴按 5 秒估的）， 只用来比较不同参数的相对大小，不要当精确值。

退料参数 C3 降级模式：先连续拉，拉不出来再蠕动

顺序是「先连续、后蠕动」：打印机报 ams_status=260（切完刀、挤出机已跑回冲刷区、 该我们收线了）之后，立刻全速连续拉料，最长「连续退料」毫秒；期间每 250ms 查一次挤出机 MQTT 信号（hw_switch_state），一报"挤出机已空"就停，再多拉 0.5 秒收尾。
拉满时间还没等到信号，才退回慢速蠕动：拱「蠕动轮数上限」轮，每轮「蠕动退料时长」， 轮间等「蠕动间隔」（同时查信号）。轮数填 0 = 不做蠕动，只连续退料。
GPIO模式等信号：只有挤出机信号来源选了 GPIO 才会用到（C3 默认走 MQTT，用不到）。
⚠️ 蠕动速度在下面「蠕动参数」里调。实测 45% 占空比完全带不动电机 （24 秒蠕动一根料都没拉动），别把蠕动速度调低于 60%。

换料温度 退料 / 进料前先把热端升到这个温度

换料时固件会先发 M109 S<温度> 把热端升到这个温度，再退料 / 进料。
太低：热端里那段料是硬的，退不出来，远端电机硬拽会打滑、拉断、磨出屑。 太高：PLA 之类会烤糊、拉丝、堵头。
参考值：PLA 220 / PETG 250 / ABS 260 / TPU 230。 范围 150~300℃，未设置时默认 250。

三条通路互斥，改完要重启才生效。原因很简单：它们都能表达 「打印机要换料」，同时开着就是两份指令抢同一个状态机 —— 一条说送料、 另一条说退料，电机听谁的？所以切换只写配置，由重启决定这次起哪一条。
WiFi 上电就启动（默认开）：开着 → 网页随时能看 485 报文， 但 WiFi 占用 ADC2，微动 6/7/8（GPIO11/12/13）读不到； 关掉 → 那三路立刻恢复正常，但重启后网页打不开 （要改回来只能重新烧录）。所以顺序是：先开着调通 485， 最后再关。
自动（推荐）：开机先起 RS-485；WiFi 上电开关开着时 两者同时跑（不启 MQTT）；关着时才走原来的逻辑 —— 2 分钟内收到打印机任何一帧 → 保持 485 不开 WiFi；收不到 → 关掉 485、开 WiFi 走 MQTT。只在开机判定一次，运行期不来回切。
RS-485 + WiFi 同时（调试专用）：WiFi 开机就起来，485 照常跑， 不启 MQTT。专门用来解决一个现场问题 —— 自动模式下开机 2 分钟没有 WiFi，而打印机的总线枚举（广播 / 点名 / 握手） 只在上电那一小会儿做，等网页能连上时全过程早就结束了。 选这个模式重启，就能一边看网页一边看 485 的实时握手。 代价是微动 6/7/8（ADC2）读不到 —— 排查完请切回「自动」。
原始报文在哪看：下面「485 总线」那一行的 「原始报文」链接，或直接访问 /bus485raw。它吐的是从上电第一帧开始的双向记录 （毫秒时间戳 + RX/TX + 十六进制），所以就算 WiFi 是两分钟后才 起来的，「自动」模式下那 2 分钟的握手也照样能回看。
RS-485：挂在打印机的 485 总线上，由打印机自己下发 「选中第几号槽 / 送料 / 退料」（不需要后处理脚本）。 保留 WiFi，网页随时能访问 —— 调试时选这个；代价是微动 6/7/8 降级。
MQTT：我们主动连打印机的 MQTT Broker，靠解析 G-code 信令判断 要换哪一路（需要切片后处理脚本把颜色映射到槽号）。
485 本次的边界：能应答注册 / 心跳 / 耗材信息（打印机界面里 能看到 AMS-A + AMS-B 共 8 个槽，颜色和温度都取自本页配置）， 但收到运动指令只把原始帧写进日志、不驱动电机 —— 字段含义要拿 真机抓帧确认后才放开，照别人的逆向结论硬套会把料退错方向。

微动开关 每路 2 只：开始位 / 停止位（合占 1 个 ADC 口）

挤出机到位-
信号来源-
★ 本版接线（2026-10-22 起）：每路只用 1 个 ADC 口读两只微动
开始位微动（常开）串 4.7K、停止位微动（常闭）串 10K， 两只并在同一个 GPIO 上，靠读电压分三档： ≈220mV = 开始位压下（缓冲器空，要补料）· ≈600mV = 中间（保持上一拍）· ≈3300mV = 停止位顶开（满了，停）。
旧的「三只微动」接法（含第三只「自吸微动」）只剩 ESP32-C3 还在用； 「自吸上料」功能已整套删除，现在每路只有下面这两只。
两只微动各自的作用：
停止送料：触发 → 立刻停电机。料到位 / 料尽 / 机构顶到头都会触发它。
开始送料：触发 → 按常规速度送料，直到停止送料微动触发或超时。
开关怎么对应：「缓冲送料」这一个开关管停止送料 + 开始送料 这两只。
打印中 / 流量校准阶段（缓冲器闭环）：
· 开了「缓冲送料」的通道 → 送与停由缓冲器微动决定 （开始送料微动触发就补料，停止送料微动触发就停）， 不再按时间间隔盲目送料。
· 微动连续 15 秒一点动作都没有 → 判定微动没反馈， 自动退回原来的「按时间间隔辅助送料」，先把这场打印跑完； 微动一恢复动作就自动回到缓冲闭环。
微动触发的两道门禁：
· 没有打印任务时不动作（空闲 / 打完 / 失败）—— 开机震动、放料时手碰到微动，都不会让电机自己转起来。
· 只有「当前通道」算数 —— 打印时打印机只用一路， 其他路的微动触发了也不动作。
上面「门禁」那一行会实时显示这两道门的状态。
换料时不看微动：
换料的送料只认打印机的「耗材已到挤出机」信号， 途中不执行「停止送料微动触发就停」。原因是缓冲器阻力比挤出机小， 料会先在缓冲器里堆住把微动顶住 —— 按它停料就到不了挤出机， 打印机随后就报故障。手动「送料」按钮仍然按微动停（那是给你调试 缓冲区用的动作）。
· 开关关掉 → 这一路退回降级模式（按时间 / 闭环推进送料， 时长由固件里的 AMS_NO_LIMIT_LOAD_MS / RETRACT_MS 决定）。

蠕动送料参数 换料收尾用

速度越低、脉冲越短 → 越"温柔"，但也越可能没把料咬住； 次数越多 → 越可靠，但每多一次就多一次机械磨损。 默认 3 次 × 400ms @ 70%。
⚠️ 「速度」低于 60% 会带不动本机构的电机：现象是"电机不转、也听不到声"， 那是占空比太低在堵转，不是指令没发出去。实测 45% 时蠕动退料跑满 24 秒 一根料都没拉动。要调慢就加长「单次时长」，别把速度往下压。

要传的是 idf.py build 出来的 esp-ams-s3.bin （或 build/esp-ams-s3.bin）。 传错文件不会造成损坏 —— 设备会检查首字节是不是 0xE9， 不是就直接中止，分区一个字节都不动。
